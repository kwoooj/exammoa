# Figma Make 제작 프롬프트

아래 구분선 사이의 내용을 전부 복사해 Figma Make에 입력한다.

이 프롬프트는 2026-08-14 기준 시험모아 화면 정의와 실제 일정 데이터를 반영한다. 날짜, 서비스 목적, 화면 우선순위, 일정 표현 규칙을 임의로 바꾸지 않는다.

---

## 작업 요청

한국의 자격증·어학 시험 일정을 한곳에서 검색하고 월간 캘린더로 비교한 뒤 공식 접수 사이트로 이동할 수 있는 반응형 웹 서비스 **시험모아**의 고품질 UI 프로토타입을 만들어줘.

코드나 기존 화면의 레이아웃은 따라 하지 말고, 아래 제품 정의와 사용자 흐름을 기준으로 새로 설계해줘.

로그인과 백엔드는 없다. 현실적인 mock data를 사용하고 주요 탐색 인터랙션이 실제로 동작하는 프론트엔드 프로토타입으로 만들어줘.

## 제품 정의

시험모아는 개인 일정 관리 앱이 아니라 **여러 시행기관에 흩어진 시험 일정과 원서접수 정보를 모아 보여주는 정보 허브**다.

사용자는 다음 네 가지를 빠르게 해결해야 한다.

1. 찾는 시험이 있는지 검색한다.
2. 현재 접수 중인지 확인한다.
3. 접수 기간과 시험 기간을 월간 캘린더에서 본다.
4. 공식 시험정보 또는 원서접수 사이트로 이동한다.

제품의 핵심 문장:

> 흩어진 시험 일정을 한곳에서 확인하고 공식 접수처로 바로 이동하세요.

## 핵심 설계 원칙

- 로그인하지 않아도 모든 핵심 기능을 사용할 수 있어야 한다.
- 시험을 선택하지 않아도 이번 달 전체 일정을 볼 수 있어야 한다.
- 일정은 줄글이나 긴 카드 목록보다 **월간 캘린더를 기본 표현**으로 사용한다.
- 목록은 검색 결과와 접근성 대체 표현으로만 사용한다.
- 공식 일정과 사용자가 가정한 날짜를 절대 같은 모양으로 표시하지 않는다.
- 일정이 겹친다는 이유만으로 위험 또는 충돌 경고를 만들지 않는다.
- 공식 링크가 화면의 명확한 종착점이어야 한다.
- 데이터 출처와 마지막 확인일을 숨기지 않는다.
- 카드 장식보다 시험명, 기관명, 상태, 날짜, 공식 링크를 우선한다.

## 만들 화면

다음 4개 핵심 화면과 주요 상태를 만든다.

1. 홈
2. 시험 일정 탐색
3. 시험 상세
4. 통합 캘린더

각 화면은 데스크톱 1440px과 모바일 390px에서 완성된 레이아웃을 제공한다.

프로토타입 라우트:

- `/` 홈
- `/exams` 시험 일정 탐색
- `/exam/정보처리기사` 시험 상세
- `/calendar?exams=정보처리기사,SQLD,토익&month=2026-10` 통합 캘린더

## 공통 디자인 방향

실제 운영 중인 검색·정보 서비스처럼 단정하고 신뢰감 있게 디자인해줘.

한국 공공정보 포털의 신뢰성과 현대적인 생산성 도구의 밀도 사이를 목표로 한다.

### 원하는 인상

- 깔끔함
- 직관적임
- 신뢰할 수 있음
- 정보 밀도가 있지만 답답하지 않음
- 장식보다 내용이 먼저 읽힘
- AI가 자동 생성한 랜딩페이지처럼 보이지 않음

### 금지

- 그라디언트
- 글래스모피즘
- 장식용 블러와 글로우
- 히어로 일러스트와 목업 이미지
- 의미 없는 통계 차트
- 모든 영역을 둥근 카드로 만드는 구성
- 큰 숫자 중심의 SaaS 대시보드
- 과도한 pill UI
- 이모지 아이콘
- 알림 벨, 프로필, 로그인 버튼
- 사이드바 내비게이션
- 후기, 강의, 교재 광고
- AI 챗봇 UI

## 캘린더 표현 규칙

이 규칙은 모든 화면에서 동일하게 사용한다.

### 공식 일정

- 원서접수 기간: 흰 배경 + 1px 테두리의 연속 막대
- 시험 기간: 짙은 잉크색으로 채운 연속 막대 + 흰 글자
- 하루짜리 시험: 짙은 잉크색 점 또는 하루 폭 블록
- 합격 발표: 흰 배경의 빈 원
- 오늘: 날짜 셀 안쪽 2px accent 테두리 + `오늘` 텍스트
- 지난 일정: 불투명도 또는 채도를 낮추되 읽을 수 있게 유지
- 데이터 오래됨: warning 색의 작은 텍스트와 경고 아이콘

색에만 의존하지 말고 모든 이벤트에 `접수`, `시험`, `발표` 라벨을 함께 표시한다.

### 기간 이벤트

- 기간이 여러 날이면 주 경계를 이어지는 연속 막대로 표시한다.
- 2026.08.07 ~ 09.01 같은 시험을 하루짜리 점으로 축약하지 않는다.
- 한 달을 넘어가면 현재 달의 마지막 날까지 막대를 이어 그리고 다음 달에도 계속됨을 표시한다.
- 막대 안에는 시험 약칭과 일정 종류를 표시한다.
- 같은 시행그룹의 일정은 중복 막대를 만들지 않는다.

### 개인 계획

개인 계획은 기본 화면에서 숨기고 `내 계획`을 켰을 때만 표시한다.

- 기간 시험의 가정 날짜: accent 마름모 + `가정`
- 상시시험의 예약일: accent 마름모 + `예약일`
- 공식 일정에는 마름모를 사용하지 않는다.
- 가정 날짜를 표시해도 원래 공식 기간 막대는 유지한다.
- 같은 날 계획이 두 개면 작은 안내 문구만 보여주고 위험 경고로 만들지 않는다.

## 화면 1 — 홈

### 목적

처음 방문한 사용자가 서비스 용도를 바로 이해하고 시험 검색 또는 이번 달 일정 탐색을 시작하게 한다.

### 데스크톱 구성

위에서 아래 순서:

1. 공통 헤더
2. 검색 중심 히어로
3. 상태별 바로가기
4. 현재 접수 중인 시험 목록
5. 분야별 시험
6. 이번 달 캘린더 미리보기
7. 데이터 신뢰 안내와 푸터

### 검색 히어로

- 헤드라인: `흩어진 시험 일정을 한곳에서 확인하세요`
- 설명: `접수 기간과 시험일을 비교하고 공식 접수처로 바로 이동할 수 있어요.`
- 큰 검색창 placeholder: `시험명 또는 시행기관 검색`
- 검색 버튼: `시험 찾기`
- 히어로 높이를 과도하게 키우지 않는다.
- 이미지와 일러스트는 사용하지 않는다.

### 상태별 바로가기

버튼 4개:

- 현재 접수 중
- 곧 접수 시작
- 이번 달 시험
- 상시시험

직사각형 버튼 또는 얇은 보더 영역으로 만든다. 큰 pill 칩으로 만들지 않는다.

### 지금 접수 중

가로 카드가 아닌 세로 목록으로 최대 5개를 보여준다.

실제 예시:

- KBS한국어능력시험 · 추가접수 · 2026.08.16까지
- TOEIC 제577회 · 원서접수 · 2026.08.17까지
- TOEIC 제576회 · 특별추가접수 · 2026.08.20까지
- 위험물기능사 · 실기 원서접수 · 2026.08.24까지

각 행:

- `접수 중` 상태
- 시험명
- 기관명
- 접수 종료일
- `상세 일정`
- `원서접수 ↗`

### 분야별 시험

카테고리:

- IT·개발
- 사무·회계
- 안전·환경·품질
- 전기·기계·건설
- 서비스·상담
- 조리·미용·운전
- 어학·국어·한국사

각 분야에는 대표 시험 2~3개만 보여준다. 62개 시험을 모두 펼치지 않는다.

### 이번 달 캘린더 미리보기

- 2026년 8월 월간 격자
- 월요일 시작 7열
- 오늘은 8월 14일
- 정보처리기사 필기시험 8월 7일~9월 1일 기간
- SQLD 제62회 시험 8월 22일
- KBS한국어 제92회 시험 8월 23일
- TOEIC과 TOEIC Speaking 일정을 일부 표시
- 홈에서는 하루 최대 2개 라벨만 노출
- 나머지는 `외 N건`
- 우측 상단 `전체 캘린더`

### 모바일

- 히어로를 짧게 유지한다.
- 상태별 바로가기는 2열
- 현재 접수 중 목록은 세로
- 캘린더는 7열을 유지
- 날짜 셀 라벨은 한 줄, 10~11px

## 화면 2 — 시험 일정 탐색

### 목적

시험명, 분야, 기관, 상태, 기간으로 원하는 시험을 찾고 통합 캘린더에 추가한다.

### 상단

- 페이지 제목 `시험 일정 찾기`
- 넓은 검색창
- 필터:
  - 분야
  - 상태
  - 기간
  - 일정 종류
  - 시험 유형
  - 시행기관
- 결과 개수
- 정렬:
  - 마감 가까운 순
  - 시험 가까운 순
  - 시험명 순

### 검색 결과 행

카드보다 리스트 행에 가깝게 만든다.

각 행:

- 캘린더 선택 체크박스
- 상태 배지
- 시험명
- 시행기관
- 가장 가까운 접수 일정
- 가장 가까운 시험 일정
- 최종 확인일
- `상세 일정`
- `원서접수 ↗` 또는 `공식 정보 ↗`

예시 행:

```text
[✓] [접수 예정]
정보처리기사
한국산업인력공단
실기 접수 09.21 ~ 10.19
실기시험 10.24 ~ 11.13
[상세 일정] [원서접수 ↗]
```

1개 이상 선택하면:

- 데스크톱 헤더에 `캘린더 1`
- 모바일 하단에 `1개 캘린더로 보기`
- 최대 6개 선택

### 모바일

- 필터 버튼을 누르면 하단 시트
- 활성 필터만 검색창 아래 작은 칩으로 표시
- 한 결과에서 시험명, 상태, 다음 접수일, 공식 링크가 먼저 보이게 한다.

## 화면 3 — 시험 상세

### 목적

검색엔진과 내부 검색으로 들어온 사용자에게 한 시험의 현재 상태, 월간 일정, 출처를 보여주고 공식 사이트로 연결한다.

### 상단 요약

예시:

```text
IT·개발 > 정보처리기사

정보처리기사
한국산업인력공단 · 정기시험
최종 확인 2026.08.14

[접수 예정]
실기 원서접수
2026.09.21 ~ 10.19

[원서접수 ↗] [공식 시험정보 ↗] [통합 캘린더에 추가]
```

- 시험명과 기관명이 가장 먼저 읽혀야 한다.
- 공식 CTA를 다른 버튼보다 명확하게 강조한다.
- `원서접수`와 `공식 시험정보`를 구분한다.

### 일정 캘린더

- 현재 또는 다음 중요한 일정이 있는 달을 기본으로 연다.
- 월 이동 `‹ 2026년 10월 ›`
- 회차 선택 `2026년도 제3회`
- 정보처리기사의 실기 접수 기간과 실기시험 기간을 연속 막대로 표시
- 막대를 선택하면 캘린더 아래 상세 패널을 연다.

상세 패널:

```text
정보처리기사 실기시험
2026.10.24 ~ 11.13
시험 기간

[공식 공고 확인 ↗]
[통합 캘린더에서 보기]
```

하단에는 접을 수 있는 `날짜순 일정표`와 출처 영역을 제공한다.

출처 예시:

```text
출처 한국산업인력공단
API · 최종 확인 2026.08.14
일정은 참고용이며 공식 공고가 우선합니다.
```

### 상시시험 상세 상태

컴퓨터활용능력 1급 예시:

```text
컴퓨터활용능력 1급
대한상공회의소 · 상시시험

확정된 연간 시험일이 없는 상시시험이에요.
접수와 시험 가능 일자는 공식 사이트에서 확인해 주세요.

접수 규칙: 시험일 4일 전까지
마지막 규칙 확인: 2026.08.01

[공식 시험일 확인 ↗] [원서접수 ↗]
```

공식 날짜가 없으므로 빈 월간 달력을 크게 보여주지 않는다.

### 모바일

- 시험명, 상태, 다음 일정, 공식 CTA가 첫 화면 안에 들어온다.
- 캘린더 7열 유지
- 일정 선택 시 상세를 하단 시트로 연다.

## 화면 4 — 통합 캘린더

이 화면을 가장 정교하게 설계해줘.

### 목적

공식 시험 일정을 월간 격자에서 탐색하고 선택한 1~6개 시험을 같은 달력에서 비교한다.

독립적인 충돌 분석 화면이 아니다. 비교는 캘린더의 선택 상태다.

### 데스크톱 레이아웃

- 상단 제목 `시험 일정 캘린더`
- 링크 복사 버튼
- 검색과 필터
- 선택한 시험 칩
- 월 이동과 오늘 버튼
- 공식 일정 / 내 계획 토글
- 좌측 약 820px 월간 캘린더
- 우측 약 300px 선택 일정 상세 패널
- 아래 범례와 날짜순 일정표

상단 예시:

```text
시험 일정 캘린더                         [링크 복사]

[시험 검색] [분야] [기관] [접수✓ 시험✓ 발표○]

선택한 시험
[정보처리기사 ×] [SQLD ×] [TOEIC ×] [시험 추가]

[‹] 2026년 10월 [›] [오늘]       [공식 일정] [내 계획]
```

### 캘린더에 표시할 2026년 10월 일정

- 정보처리기사 실기 원서접수: 9월 21일~10월 19일
- 정보처리기사 실기시험: 10월 24일~11월 13일
- SQLD 제63회 원서접수: 10월 12일~10월 16일
- KBS한국어 제93회 추가접수: 10월 3일~10월 11일
- KBS한국어 제93회 시험: 10월 18일
- KBS한국어 제93회 성적발표: 10월 29일
- TOEIC 제583회 원서접수: 10월 12일~11월 16일

일정 막대가 겹치면 캘린더 행 안에서 위아래로 쌓는다. 겹치는 영역에 경고 배경을 칠하지 않는다.

### 날짜 상세 패널

캘린더에서 10월 24일 또는 정보처리기사 실기시험 막대를 선택한 상태를 보여준다.

```text
정보처리기사 실기시험
한국산업인력공단

2026.10.24 ~ 11.13
시험 기간

[공식 시험정보 ↗]
[이 기간 중 날짜 가정하기]
```

`날짜 가정하기`는 보조 버튼이다. 공식 CTA보다 강조하지 않는다.

### 내 계획 상태

기본 화면은 `공식 일정` 상태다.

`내 계획`을 켠 두 번째 상태도 만들어줘.

- 정보처리기사 실기시험 가정 날짜: 2026.10.31
- 캘린더에 accent 마름모 + `정처기 가정`
- 공식 실기시험 기간 막대는 그대로 유지
- 안내: `공식 예약이 아닌 개인 계획용 표시예요`
- 같은 날 다른 계획이 있다면 `이 날 다른 시험 계획이 있어요`
- 위험, 충돌, 오류라는 단어는 사용하지 않는다.

### 계획 입력 시트

기간 시험:

```text
정보처리기사 실기시험
2026.10.24 ~ 11.13 중 하루

[날짜 선택 캘린더]

공식 예약이 아닌 개인 계획용 표시예요.
[취소] [가정 날짜 표시]
```

상시시험:

```text
컴퓨터활용능력 1급
상시시험

아직 예약하지 않았다면 목표 월만 표시할 수 있어요.
[10월] [11월] [12월]

공식 사이트에서 예약했다면 날짜를 기록하세요.
[예약한 시험일 입력]

[취소] [내 계획에 표시]
```

목표 월은 캘린더 날짜 막대로 그리지 않는다. 예약한 시험일만 마름모로 표시한다.

### 전체 일정 모드

선택한 시험이 없어도 통합 캘린더를 사용할 수 있다.

- 검색과 분야·기관·이벤트 필터
- 하루 최대 3개 라벨
- 나머지는 `외 N건`
- 날짜 선택 시 해당 날짜의 전체 일정 목록
- 동일 시행그룹의 중복 일정은 한 번만 표시

### 모바일

- 7열 월간 캘린더 유지
- 가로 스크롤 금지
- 날짜 셀 최소 높이 68px
- 일정 라벨 한 줄, 10~11px
- 상세 패널 대신 하단 시트
- 필터와 시험 추가도 하단 시트
- 일정이 많은 달에는 달력 아래 날짜순 목록

## 인터랙션

프로토타입에서 아래 동작을 연결해줘.

1. 헤더 검색 → 시험 일정 탐색으로 이동
2. 자동완성에서 정보처리기사 선택 → 시험 상세로 이동
3. 탐색 결과 체크박스 → 캘린더 선택 개수 증가
4. `캘린더로 보기` → 선택한 시험이 담긴 통합 캘린더
5. 캘린더 이전 달·다음 달 이동
6. 이벤트 막대 선택 → 데스크톱 상세 패널 또는 모바일 하단 시트
7. `날짜순 일정표` 펼치기·접기
8. `내 계획` 토글
9. 기간 시험 `날짜 가정하기` → 날짜 선택 시트
10. 상시시험 `공식 시험일 확인`과 `원서접수` 외부 링크 상태
11. 링크 복사 → `캘린더 링크를 복사했어요` 토스트
12. 모바일 필터 시트 열기·닫기

## 빈 상태와 오류 상태

다음 상태를 최소한 컴포넌트 수준으로 준비해줘.

### 검색 결과 없음

```text
조건에 맞는 시험을 찾지 못했어요.
접수 상태 또는 기간 필터를 줄여 보세요.
[필터 초기화]
```

### 일정 미공고

```text
2027년 일정이 아직 발표되지 않았어요.
공식 기관에 일정이 게시되면 시험모아에도 반영됩니다.
[공식 시험정보 확인 ↗]
```

### 데이터 오래됨

```text
마지막 확인 5일 전
이전 확인 정보를 표시하고 있어요.
[공식 사이트에서 확인 ↗]
```

### 전체 상시시험

빈 캘린더를 보여주지 말고 상시시험 규칙 카드와 공식 링크 목록을 보여준다.

## 접근성

- 본문과 배경 대비 WCAG AA
- 최소 터치 영역 44×44px
- 모든 입력에 명확한 label
- 포커스 링 유지
- 상태를 색만으로 구분하지 않음
- 외부 링크의 새 창 이동 표시
- 캘린더 아래 동일 정보를 가진 날짜순 표
- 날짜에는 기계 판독 가능한 전체 연·월·일 의미 제공
- 아이콘 단독 버튼에 접근성 이름 제공

## 문구 원칙

- 짧고 사실적으로 쓴다.
- 느낌표를 쓰지 않는다.
- 버튼은 행동이 드러나게 쓴다.
- 운영 데이터 용어인 parsed, manual, stale을 노출하지 않는다.
- D-Day를 단독으로 크게 강조하지 않는다.

사용할 문구:

- `시험명 또는 시행기관 검색`
- `현재 접수 중`
- `곧 접수 시작`
- `전체 캘린더`
- `통합 캘린더에 추가`
- `원서접수 ↗`
- `공식 시험정보 ↗`
- `날짜순 일정표`
- `이 기간 중 날짜 가정하기`
- `예약한 시험일 표시`
- `일정은 참고용이며 공식 공고가 우선합니다`

## 최종 검수

완성 후 반드시 확인해줘.

- 로그인 UI가 없는가?
- 홈에서 시험을 선택하지 않아도 일정이 보이는가?
- 시험 일정이 월간 캘린더를 중심으로 표현되는가?
- 기간 시험이 여러 날짜를 잇는 막대로 보이는가?
- 정보처리기사 필기시험을 하루짜리 점으로 만들지 않았는가?
- 상시시험에 임의의 공식 날짜를 만들지 않았는가?
- 공식 일정과 가정 날짜의 모양이 다른가?
- 기간 겹침을 위험이나 충돌로 표시하지 않았는가?
- 공식 링크가 명확한가?
- 시행기관과 마지막 확인일이 보이는가?
- 하루에 일정이 많을 때 `외 N건` 처리가 있는가?
- 모바일에서 가로 스크롤 없이 7열 달력을 볼 수 있는가?
- 모바일 일정 상세가 하단 시트로 열리는가?
- 카드, pill, 그림자, 액센트 컬러를 과도하게 사용하지 않았는가?
- 헤더·버튼·필터·목록·캘린더 이벤트가 재사용 가능한 컴포넌트인가?

# Figma Make 프롬프트

아래 `---` 사이 전체를 복사해서 Figma Make에 붙여넣는다.
데이터·제약은 실측값(2026-08-13 수집)을 그대로 넣었으므로 임의로 바꾸지 말 것. 바꾸면 와이어프레임이 실제 데이터와 어긋난다.

---

## 만들 것

한국 취업 준비생이 **동시에 준비하는 자격증·어학 시험의 응시일을 정하고, 원서접수 마감과 시험일까지 남은 날짜를 한눈에 보는 웹사이트**의 와이어프레임. 일정 전체는 가로 타임라인으로 함께 보여준다. 서비스명은 exammoa.

로그인 없음. 화면은 3개(종목 선택, 타임라인, 월간 달력) + 시트 1개(응시 예정일 지정).

핵심 가치는 **"내가 정한 시험 일정이 며칠 남았는지 한눈에 보는 것"**이다. 이 문장이 화면 설계의 기준이다.

충돌을 3단계로 분류해 알려주는 방식은 **폐기했다.** 실측에서 시험 이벤트의 98%가 기간 시행(필기 26일·실기 21일)이라 기간끼리는 거의 항상 겹치고, 그래서 '겹친다'는 사실 자체가 정보가 되지 못했다. 실제 화면에 충돌 117건이 떴고 그중 106건이 "접수 기간이 겹쳐요"였다 — 접수는 겹쳐도 순서대로 하면 되므로 사용자가 할 일이 없다.

대신 이렇게 한다.

- 사용자가 **응시일을 지정**한다 (기간 시행이면 그 기간 안에서 하루를 고른다)
- 지정한 시험일과 원서접수 마감일의 **D-Day를 가까운 순으로** 보여준다
- 이미 지정한 시험일과 같은 날을 고르면 그 자리에서 `이미 2026.10.11에는 정보처리기사 실기시험이 있습니다`

## 디자인 방향

블랙 앤 화이트. 미니멀하고 깔끔하며 세련된, 타이포그래피 주도 디자인. 스위스 그리드 감각. 데이터 밀도가 높은 화면이지만 답답하지 않게 여백을 넉넉히 둔다.

- 색은 흑백과 회색 4단계만 사용한다. 액센트 컬러 없음
- 헤어라인 보더(0.5px~1px). 카드에 그림자 대신 얇은 선
- 그라디언트, 드롭섀도, 글로우, 라운드가 큰 pill 버튼 금지
- 라운드는 최대 8px. 대부분 4px 또는 각지게
- 이모지 금지. 아이콘은 아웃라인 스타일, 선 굵기 1.5px

### 디자인 토큰

```
색
  ink            #0A0A0A   본문, 강조
  ink-secondary  #52514E   보조 텍스트
  ink-muted      #8E8C86   캡션, 축 라벨
  line           #E3E1DB   기본 보더
  line-strong    #B5B3AB   강조 보더
  surface        #FFFFFF   카드
  canvas         #FAFAF8   페이지 배경

타이포 — Pretendard (없으면 Inter + 한글 fallback)
  Display  32 / 40  Medium     페이지 타이틀
  H1       22 / 30  Medium
  H2       17 / 24  Medium
  Body     15 / 24  Regular
  Small    13 / 20  Regular    보조 설명
  Caption  11 / 16  Regular    축 라벨, 배지
  Mono     13 / 20             날짜 표기에만 (숫자 정렬)
  굵기는 Regular(400)과 Medium(500) 두 단계만 사용

간격  4 / 8 / 12 / 16 / 24 / 32 / 48
그리드 최대 폭 1080px, 좌우 여백 데스크톱 32px · 모바일 20px
```

### 색 없이 정보를 구분하는 방법 — 중요

액센트 컬러가 없으므로 **이벤트 종류와 심각도를 색으로 구분할 수 없다.** 반드시 형태로 구분한다.

이벤트 종류:

- **원서접수** — 속이 빈 막대. 1px 실선 테두리, 배경 흰색
- **시험** — 꽉 찬 검정 막대(기간 시행) 또는 검정 원(하루)
- **합격발표** — 속이 빈 원. 1px 테두리, 배경 흰색

지정한 응시일:

- **응시 예정 마커** — 속이 찬 작은 마름모 + `예정` 캡션. 원래 기간 막대는 투명도 25%로 내린다

D-Day 목록에서 두 종류를 구분하는 방법:

- **시험일** — 좌측에 2px 검정 보더, D-Day 숫자를 Medium
- **원서접수 마감** — 보더 없음, D-Day 숫자를 Regular

색이 없으므로 굵기와 보더로만 구분하되 **텍스트 라벨을 반드시 병기**한다.

## 화면 1 — 종목 선택 (홈)

첫 방문자가 3초 안에 무엇을 하는 곳인지 알고, 30초 안에 종목 2~3개를 고르게 한다.

구성 (위에서 아래로):

1. 얇은 헤더 — 좌측 서비스명 `exammoa`, 우측 선택 개수 배지(`3개 선택`, 1개 이상일 때만)
2. 헤드라인 2줄 — "준비하는 시험을 고르고 응시일을 정하면 / 남은 날짜를 모아 보여드려요". Display 사이즈
3. 검색 입력 — 한 줄, 높이 44px, 플레이스홀더 `시험 이름 검색 (예: 정처기)`
4. 카테고리 섹션 7개. 각 섹션은 Small 사이즈 회색 제목 + 아래 칩 그리드
   - `IT · 개발` / `사무 · 회계` / `안전 · 환경 · 품질` / `전기 · 기계 · 건설` / `서비스 · 상담` / `조리 · 미용 · 운전` / `어학 · 국어 · 한국사`
5. 칩 — 높이 36px, 라운드 4px, 1px 보더, 배경 흰색. 선택 시 배경 검정 + 글자 흰색 + 좌측에 체크 아이콘
   - 칩 안에 종목명. 상시시험 종목은 우측에 `상시` 캡션 배지
   - 시행기관이 한국산업인력공단이 아닌 종목은 칩 아래 Caption으로 기관명 표기 (`한국데이터산업진흥원` 등)
6. "찾는 시험이 없나요?" + 텍스트 링크
7. 하단 고정 바 — 선택한 종목명을 `·`로 나열, 우측에 `일정 보기` 버튼(검정 배경). 선택 0개면 비활성 + `시험을 1개 이상 골라주세요`

칩에 넣을 실제 종목명: 정보처리기사, 정보처리산업기사, 산업안전기사, 위험물산업기사, 전기기사, 전기산업기사, 소방설비기사(전기분야), 건축기사, 토목기사, 품질경영기사, 직업상담사 2급, 사회조사분석사 2급, 지게차운전기능사, 굴착기운전기능사, 전기기능사, 위험물기능사, 한국사능력검정시험, TOEIC, TOEIC Speaking, KBS한국어능력시험, 컴퓨터활용능력 1급(상시), 컴퓨터활용능력 2급(상시), 워드프로세서(상시), OPIc(상시), SQLD, ADsP, 빅데이터분석기사

최대 8개까지 선택 가능. 9번째 시도 시 토스트 `최대 8개까지 선택할 수 있어요`.

## 화면 2 — 타임라인 (가장 중요)

이 화면 하나가 서비스의 전부다. 여기에 가장 많은 공을 들인다.

### 레이아웃

1. 헤더 — 좌측 `← 시험 바꾸기`, 우측 `링크 복사` 아이콘 버튼 + 선택 개수
2. 범례 한 줄 — 위에서 정의한 세 가지 형태와 이름. Caption 사이즈
3. **타임라인 본체**
   - 좌측 종목 라벨 컬럼: 데스크톱 120px, 모바일 76px 고정
   - 우측 트랙 영역: 오늘부터 6개월. 월 경계마다 1px 세로 실선(`line` 색), 상단에 월 라벨(`8월` `9월` …)
   - **오늘 위치에 2px 검정 수직선.** 상단에 `오늘` 캡션
   - 행 높이 40px, 막대 높이 10px, 원 지름 10px
   - 지난 이벤트는 투명도 35%
4. **다가오는 일정** — 이 화면에서 가장 중요한 블록이다. 타임라인 바로 위에 놓는다. 지정한 시험일과 원서접수 마감일만, D-day 오름차순. `D-9`·`D-DAY` 는 Mono 17px Medium, 종목명 Body Medium, 이벤트명 Small 회색, 날짜 Small 회색 우측 정렬. 지난 항목은 담지 않는다
5. 지정한 것이 없으면 `시험을 고르고 응시일을 정하면 여기에 D-Day가 가까운 순으로 쌓여요` 를 점선 테두리 안에
6. **상시시험 카드** — 타임라인 밖 별도 영역. 확정 일정이 없으므로 막대를 그리지 않는다
7. 푸터 — `최종 확인: 2026.08.13` / `일정은 참고용이며 공식 공고가 우선합니다`

### 행 구성 — 반드시 이렇게

행은 **시행그룹별**로 만든다. 종목별이 아니다. 실측 결과 47종목의 연간 일정이 실제로는 7가지뿐이었고 그중 하나에 29종목이 몰려 있다. 종목별로 행을 그리면 같은 막대가 29줄 반복되고 정보량이 0이 된다.

행 라벨은 사용자가 고른 종목 이름으로 쓴다. 한 그룹에서 2개 이상 골랐으면 `정보처리기사 +2` 로 표시하고 누르면 나머지 이름을 펼친다. 그룹 이름 아래에 시행기관을 Caption 으로 반드시 병기한다 — "빅데이터분석기사"처럼 이름에 기사가 붙지만 공단 일정과 무관한 종목이 있어서, 기관 표기가 없으면 같은 일정으로 오인된다.

### 실제 데이터로 채울 것 (정보처리기사 2026년 3회)

```
필기 원서접수    2026-07-20 ~ 2026-07-23   (빈 막대)
필기 빈자리접수  2026-08-01 ~ 2026-08-02   (빈 막대, 라벨에 '빈자리' 표기)
필기시험         2026-08-07 ~ 2026-09-01   (꽉 찬 막대 — 26일간 CBT 기간 시행)
필기 합격발표    2026-09-09                (빈 원)
실기 원서접수    2026-09-21 ~ 2026-10-19   (빈 막대)
실기시험         2026-10-24 ~ 2026-11-13   (꽉 찬 막대)
최종 합격발표    2026-12-11                (빈 원)
```

한 행에 이렇게 7개 이벤트가 들어간다. **막대가 대부분 길다**는 점이 이 화면의 시각적 특징이다. 시험이 하루짜리 점이라고 가정하고 디자인하면 실제 데이터와 완전히 어긋난다.

와이어프레임에는 4개 행을 그린다: `정보처리기사 +2`(같은 시행그룹에서 3종목을 골랐다는 뜻), `한국사능력검정시험`, `TOEIC`, `지게차운전기능사`.

`지게차운전기능사`는 연 41회 시행이라 6개월 창에 이벤트가 76개 들어온다. 개별 막대를 다 그리면 뭉개지므로 **한 행을 연속된 옅은 회색 밴드로 칠하고 `6개월 중 20회 시행` 캡션 + `응시 회차 고르기` 텍스트 버튼**을 놓는다.

### 같은 날 안내

응시일을 지정하는 시트 안에서, 지정하려는 날에 이미 다른 시험을 지정해 두었으면 그 자리에 한 줄로 띄운다.

- `이미 2026.10.24에는 산업안전기사 실기시험이 있습니다`
- 둘 이상이면 `이미 2026.10.24에는 산업안전기사 실기시험 외 1건이 있습니다`

1px 검정 테두리 박스에 13px 텍스트. **막지 않는다** — 알려주기만 하고 지정은 그대로 되게 한다. 하루에 두 시험을 보는 것이 불가능한지는 사용자가 판단한다.

같은 날이 아니면 아무것도 띄우지 않는다. 이 안내는 드물게 떠야 뜰 때 신호가 된다.

## 화면 3 — 월간 달력

사용자는 자기 일정을 월 단위 격자로 기억한다(구글 캘린더 등). 시험 일정을 자기 일정과 대조하려면 같은 형태로 보여주는 것이 직관적이다. **타임라인을 대체하지 않고 함께 둔다** — 타임라인은 6개월 밀집도를, 달력은 특정 날짜의 대조를 담당한다.

- 월요일 시작 7열. 토·일이 한 주 끝에 나란히 붙는다 (시험이 주로 주말이다)
- **한 달만** 보여주고 좌우 버튼(‹ ›)으로 이전달·다음달로 넘긴다. 여러 달을 세로로 늘어놓지 않는다 — 사용자가 쓰는 캘린더 앱과 같은 형태여야 대조가 된다
- 보고 있는 달이 이번 달이 아니면 우측에 `오늘로` 텍스트 버튼
- 표시할 일정이 없는 달이면 범례 옆에 `이 달에는 표시할 일정이 없어요`
- 앞뒤로 딸려온 인접 달 날짜는 배경을 `canvas` 로 깔고 날짜 숫자를 `ink-muted` 로
- **오늘** — 칸 안쪽에 2px 검정 테두리(`inset` 그림자). 배경을 칠하지 않는다
- 칸에 찍는 것은 두 가지뿐이다
  - **지정한 시험일** — 채운 검정 배경 + 흰 글자, 종목 약칭
  - **원서접수 마감** — 1px 테두리만, 회색 글자
- 칸 높이 데스크톱 62px / 모바일 52px. 라벨은 10px, 넘치면 줄임표
- 하단에 형태 범례 한 줄
- 지정한 것이 없으면 점선 박스에 `응시일을 정하면 달력에 표시돼요`

## 시트 — 응시 예정일 지정

타임라인의 막대를 누르면 하단에서 올라오는 시트. 이 서비스의 핵심 인터랙션이다.

시험 대부분이 기간 시행(필기 26일)이라 지정하지 않으면 D-Day 를 만들 수 없다. 사용자가 응시일을 지정하는 순간 그 시험이 고정일이 되고, 그때부터 D-Day 와 같은 날 안내가 의미를 갖는다. **지정 전에는 D-Day 자리에 `기간 중 응시일을 정하면 D-Day가 생겨요` 를 둔다.**

종목 성격에 따라 세 가지 형태를 각각 그린다.

1. **기간 시행** — `정보처리기사 필기시험` / `2026.08.07 ~ 2026.09.01 중 하루` / 기간 안의 날짜를 고르는 간단한 캘린더 / `이 날 볼 예정` 버튼
2. **고빈도(회차 선택)** — `지게차운전기능사` / 다가오는 회차 목록 5개를 라디오로 / 각 항목에 `제32회 · 접수 09.14~09.17 · 시험 09.28`
3. **상시시험** — `컴퓨터활용능력 1급` / `상시시험이라 확정 일정이 없어요` / `접수는 시험일 4일 전까지` / 월 단위 선택 칩 `9월` `10월` `11월` / `이 시기에 볼 예정` 버튼

지정 후 타임라인에는 해당 위치에 **속이 찬 작은 마름모 마커 + `예정` 캡션**이 찍히고, 원래 기간 막대는 투명도 25%로 내려간다.

## 상태 화면

- 일정 미공고 — 해당 행에 막대 없이 `2027년 일정 미공고` Small 텍스트
- 상시시험만 선택 — 타임라인을 그리지 않고 규칙 카드만
- 데이터가 오래됨 — 상단에 얇은 배너 `일정 정보가 3일 이상 갱신되지 않았어요`
- 특정 종목 수집 실패 — 그 행 라벨 밑에 Caption `최종 확인: 5일 전`

## 반응형

- 데스크톱 1080px, 모바일 390px 두 가지를 만든다
- **모바일에서 타임라인은 가로 스크롤을 절대 쓰지 않는다.** 6개월을 화면 폭에 맞춘다. 안 들어가면 종목 라벨을 축약하고(`정처기`), 월 라벨만 남긴다. 스크롤로 나눠 보면 "10월에 뭐가 몰려 있나"를 한 번에 볼 수 없고 그 순간 이 서비스는 존재 이유를 잃는다
- 모바일 이벤트 상세는 하단 시트
- 모바일 하단 고정 바는 세이프 에어리어 고려

## 만들지 말 것

- 월간 격자에 **기간 막대**를 칠하는 것. 26일짜리 필기 기간을 격자에 칠하면 한 달이 통째로 검게 되고 정보가 사라진다. 기간은 타임라인이 담당한다
- 로그인, 회원가입, 마이페이지, 프로필, 설정
- 알림 벨, 푸시 배너
- 액센트 컬러, 그라디언트, 그림자, 이모지
- 주별 밀집도 차트
- 사이드바 내비게이션. 화면이 3개뿐이라 필요 없다
- 히어로 이미지, 일러스트, 목업 사진

## 문구 원칙

- 문장은 짧고 담백하게. 느낌표 쓰지 않음
- 버튼은 동사로 시작 (`일정 보기`, `이 날 볼 예정`, `링크 복사`)
- 날짜는 `2026.08.07` 형식, 기간은 `2026.08.07 ~ 2026.09.01`
- D-day는 `D-9` 형식, Mono 폰트

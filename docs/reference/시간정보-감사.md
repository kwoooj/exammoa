# 시간정보 감사 — 2026-08-20

`data/published/sessions.json` 313회차·1,194이벤트와 각 기관 공식 일정 원문을 대조한 결과다. 시각이 없을 때 `00:00` 같은 값을 만들지 않고, 개인별로 달라지는 경우는 `varies` 또는 `select-on-booking`으로 저장한다.

시험 이벤트의 미기재 1건은 한국금융연수원 프라이빗뱅커 제92회다. 공식 API가 시험시간을 `~`로 공고해 임의 시각을 만들지 않았다. 같은 날짜라도 시간이 다른 세무사회 10종과 리눅스마스터 1·2급은 별도 시행그룹으로 분리해 공식 시각을 보존한다.

## 이번 감사에서 발견해 반영한 값

- Q-Net 47종목: 원서접수 첫날 10:00~마지막 날 18:00, 합격자 발표 09:00. 실제 시험 시각은 접수한 시험장·일시 및 수험표에 따라 달라 `varies`로 저장.
- 한국사능력검정시험: 10:00 시작. 심화·기본의 종료 시각은 달라 시작만 확정.
- TOEIC Speaking: 일정표에는 날짜만 있고 접수 과정에서 시험시간을 선택하므로 `select-on-booking`으로 저장.
- 리눅스마스터 1·2급: 공식 페이지 하단의 등급별 시간표에서 입실완료와 시험시간을 읽는다. 기간형 온라인 회차는 `select-on-booking`으로 유지.
- 한국세무사회 10종: 전산세무·전산회계·세무회계·기업회계의 급수별 시간을 각각의 시행그룹에 저장한다.

## 남아 있는 시간 미기재와 이유

### 시험

- 프라이빗뱅커 제92회: 공식 연간 일정 API의 시험시간이 `~`라 미기재 상태를 그대로 둔다.

### 접수 94건

- DATAQ 7종: 공공데이터 CSV가 접수 시작일·마감일만 제공하고 시각 필드가 없다. 공식 사이트는 robots.txt 전체 금지라 추가 크롤링하지 않는다.
- 리눅스마스터 1·2급: 연간 일정표는 접수 날짜만 제공한다. 시작·마감 시각을 모두 확정할 수 없어 반쪽짜리 범위를 저장하지 않았다.
- 한국세무사회 10종: 연간 일정표는 접수 날짜만 제공한다. 회차별 시행공고의 별도 확인이 필요하다.

### 발표 140건

현재 수집 중인 여러 공식 연간 일정 응답은 발표 날짜만 제공하고 시각은 제공하지 않는다. 회차별 공지가 나중에 시간을 밝힐 가능성은 있지만, 연간 배치에서 안정적으로 확인되는 값이 아니므로 추정하지 않는다.

### 상시시험 5종

컴퓨터활용능력 1·2급, 워드프로세서, OPIc, ITQ는 확정 연간 회차를 만들지 않는다. 센터·좌석·접수 과정에서 사용자가 일시를 선택하는 구조라 목록에는 상시 규칙을 안내하고 수험표/예약 화면을 정본으로 둔다.

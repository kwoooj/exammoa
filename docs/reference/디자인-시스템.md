# 디자인 시스템

문서 버전 1.0.0 · 2026-08-14

**토큰의 정본은 이 문서다.** 값을 바꾸려면 여기부터 고치고 `src/styles.css` 를 맞춘다.
화면 구성은 [화면정의-전체.md](화면정의-전체.md) 가 정본이고, 이 문서는 색·글자·간격만 다룬다.

미니멀하고 깔끔한 구조. 흑백을 기본으로 하고 액센트를 절제해서 쓴다. 타이포그래피가 주도하고 장식은 없다. 앱 대시보드보다 **검색 서비스와 공공정보 포털의 중간** 인상을 목표로 한다 (화면정의 §13).

## 1. 색

### 기본

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--ink` | `#0A0A0A` | `#F2F1EE` | 본문·강조 |
| `--ink-secondary` | `#55534E` | `#B4B1A9` | 보조 텍스트 |
| `--ink-muted` | `#75736B` | `#8A8880` | 캡션·축 라벨 |
| `--line` | `#E4E2DC` | `#2A2A2E` | 보더 1px |
| `--line-strong` | `#B5B3AB` | `#43434A` | 진한 보더 |
| `--surface` | `#FFFFFF` | `#161619` | 카드·격자 |
| `--canvas` | `#FAFAF9` | `#0D0D0F` | 배경 |

`--ink-muted` 는 원래 `#8E8C86` 이었다. 흰 배경에서 3.3:1 로 AA(4.5:1) 미달이라 올렸다 — **캡션도 본문이다.**

### 액센트와 경고

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--accent` | `#1F4FFF` | `#8AA4FF` | 공식 링크, 활성 필터, 오늘 |
| `--warn` | `#B45309` | `#F0A45A` | 낡은 데이터·수집 실패 |

코발트 `#1F4FFF` 는 어두운 배경에서 대비가 2.6:1 로 무너져 다크 모드에서 밝은 값으로 바꾼다.

**액센트 예산 — 화면당 3곳 이하.** 지금 배정된 자리는 이것뿐이다.

1. 접수 중 · 접수 D-N 배지 (화면정의 §3.2 — 이 둘만 강조색을 쓴다)
2. 캘린더의 오늘 테두리, 그리고 P2 의 개인 계획 마름모
3. 주요 버튼과 선택된 칩 · 활성 필터

네 번째 자리를 만들고 싶으면 위 셋 중 하나를 먼저 회수한다.

**본문 링크에는 액센트를 쓰지 않는다.** 라우트가 일곱이 되고 목록·관련 시험·푸터가 전부 링크가 되면서 한 화면에 파란 글씨가 스무 개씩 떴다. 그러면 정작 눌러야 할 원서접수 버튼이 묻힌다. 내부 링크는 잉크색 + 밑줄이고, 액센트는 **기관으로 나가는 링크**(`.extlink`)에만 남긴다.

### 종목 구분 색

| 토큰 | 라이트 | 다크 |
|---|---|---|
| `--cat-1` 보라 | `#6D40B8` | `#B79CF5` |
| `--cat-2` 청록 | `#0E6C6C` | `#5CC9C3` |
| `--cat-3` 자주 | `#B03A5B` | `#F096AD` |
| `--cat-4` 초록 | `#3B7A3B` | `#86C98A` |
| `--cat-5` 황토 | `#8A5A00` | `#DFAE5E` |
| `--cat-6` 자두 | `#8B3A72` | `#E79AD0` |

**색은 어느 시험인지를 말하고, 모양은 일정 종류를 말한다.** 둘을 겹치면 화면정의 §3.2 의 "색상만으로 상태를 구분하지 않는다" 를 어기고, 색맹 사용자와 흑백 인쇄에서 접수와 시험이 같아진다.

액센트(코발트)와 경고(앰버)는 이미 다른 뜻을 갖고 있어 이 팔레트에 넣지 않는다. 여섯 개인 것은 통합 캘린더가 최대 6개까지 담기 때문이다 (화면정의 §8.3).

**시행그룹이 하나뿐인 화면에서는 색을 쓰지 않는다.** 시험 상세처럼 한 시험만 있으면 색이 아무것도 구분하지 못하고, 구분하지 않는 색은 장식이다 (§13.2).

## 2. 캘린더 막대

모양이 종류를 말한다. 색맹·흑백 인쇄·다크 모드 어디에서도 같은 구분이 남아야 한다.

| 일정 | 모양 |
|---|---|
| 접수 | 테두리 + 옅은 틴트 바탕 |
| 추가접수·빈자리·취소좌석 | **점선** 테두리 |
| 기간 시험 | 채운 막대 |
| 하루 시험 | 채운 점 |
| 발표 | 점선 원 |
| 진행 중 | 굵기를 키운다 (20 → 22px) |
| 주 경계를 넘음 | 모서리를 각지게 + `‹` `›` |

**바탕을 반드시 칠한다.** 흰 칸 위의 흰 막대에 1.5px 테두리만 두르면 달력에서 막대가 사라진다.

**지난 막대에 `opacity` 를 쓰지 않는다.** 다크 모드에서 밝은 잉크에 걸면 대비가 AA 아래로 떨어진다. `--bar-past` 전용 토큰을 쓴다.

## 3. 타이포

Pretendard (없으면 시스템 산세리프). 굵기는 **Regular 400 · Medium 500 두 단계만.**

| 용도 | 크기 |
|---|---|
| 페이지 제목 | 30/38 Medium |
| 섹션 제목 | 17/24 Medium |
| 시험명 | 17px Medium |
| 본문·날짜 | 15/24 Regular |
| 보조 | 13/20 Regular |
| 캡션·기관명 | 11/16 Regular |

날짜와 숫자는 `tabular-nums`. 한국어 종목명이 길어 자간을 `-0.005em` 로 살짝 좁힌다 — 그 이상은 좁히지 않는다 (화면정의 §13.3).

## 4. 간격·형태

```
간격  4 / 8 / 12 / 16 / 20 / 24 / 32 / 48
라운드 4 / 6 / 8   (최대 8px)
최대 폭 1040px
터치 타깃 44 × 44px
```

**그림자는 떠 있는 것에만.** 시트·하단 바·토스트·팝오버. 카드와 칩은 1px 보더뿐이다.

**카드보다 구분선·간격·타이포그래피로 정보를 나눈다** (§13.1). 모든 것을 둥근 카드에 넣지 않는다.

## 5. 하지 않을 것 (§13.2)

- 그라디언트, 유리 효과, 장식용 블러
- 의미 없는 통계 숫자와 대시보드 차트
- 필터가 아닌 문구를 pill 로 만들기
- 이모지를 아이콘 대신 쓰기
- 히어로 이미지·일러스트·목업
- 한 화면에서 강조 버튼을 여럿 경쟁시키기
- 색상만으로 상태 구분하기
- 포커스 링 제거

# Stitch 프롬프트

`## A` 전체를 복사해 새로 생성하고, 결과가 어긋나면 `## B`의 지시문을 **한 번에 하나씩** 넣어 고친다.

**이번 개정에서 빠진 것**: 충돌 심각도 3단계, 충돌 요약 섹션, 주별 밀집도.
**대신 들어온 것**: 응시일 중복 경고 한 줄, 설정한 시험의 D-Day.

---

## A. 전체 생성 프롬프트

한국 취업 준비생이 **동시에 준비하는 자격증·어학 시험의 일정을 한 화면에서 관리하는 반응형 웹앱**. 데스크톱 우선, 모바일 대응. 로그인 없음. 화면 3개.

### 디자인 시스템

미니멀하고 깔끔한 세련된 구조. 흑백을 기본으로 하고 액센트 1색만 절제해서 쓴다. 타이포그래피가 주도하고, 장식은 없다.

```
기본
  ink            #0A0A0A   본문·강조
  ink-secondary  #55534E   보조 텍스트
  ink-muted      #8E8C86   캡션·축 라벨
  line           #E4E2DC   보더 (1px)
  surface        #FFFFFF   카드
  canvas         #FAFAF9   배경

액센트 — 딱 이 두 개만
  accent         #1F4FFF   코발트 블루. 선택 상태, D-Day 숫자, 주요 버튼
  warn           #B45309   앰버. 중복 경고 한 곳에만

타이포 — Pretendard (없으면 Inter)
  Display 30/38 Medium · H2 17/24 Medium · Body 15/24 Regular
  Small 13/20 Regular · Caption 11/16 Regular
  숫자와 날짜는 tabular, D-Day는 Medium
  굵기는 Regular·Medium 두 단계만

간격 4 / 8 / 12 / 16 / 24 / 32 · 라운드 최대 8px · 그림자 없음
최대 폭 1040px
```

액센트는 화면당 3곳 이하로 쓴다. 그라디언트·그림자·이모지·히어로 이미지 없음.

### 화면 1 — 종목 고르기

- 얇은 헤더: 좌측 `exammoa`, 우측 선택 개수 (`3개 선택`, 1개 이상일 때만)
- 헤드라인 2줄: "준비하는 시험을 고르면 / 일정을 한 화면에서 볼 수 있어요"
- 검색 입력 1개, 높이 44px, 플레이스홀더 `시험 이름 검색 (예: 정처기)`
- 카테고리 6개 섹션. 각 섹션은 Small 회색 제목 + 칩 그리드
  `IT · 개발` `사무 · 회계` `안전 · 환경 · 품질` `전기 · 기계 · 건설` `조리 · 운전` `어학 · 한국사`
- 칩: 높이 36px, 라운드 6px, 1px 보더, 흰 배경. 선택 시 **보더와 글자만 accent 색**으로 바뀌고 배경은 accent 5% 틴트. 검정으로 꽉 채우지 않는다
- 상시시험 종목은 칩 우측에 `상시` Caption 배지
- 시행기관이 한국산업인력공단이 아닌 종목은 칩 하단에 Caption으로 기관명 (`한국데이터산업진흥원`)
- 하단 고정 바: 선택한 종목명을 `·`로 나열 + `일정 보기` 버튼(accent 배경, 흰 글자). 0개면 비활성

종목명 예시: 정보처리기사, 정보처리산업기사, 산업안전기사, 위험물산업기사, 전기기사, 전기산업기사, 소방설비기사(전기분야), 건축기사, 토목기사, 직업상담사 2급, 사회조사분석사 2급, 지게차운전기능사, 전기기능사, 한국사능력검정시험, TOEIC, TOEIC Speaking, KBS한국어능력시험, SQLD, ADsP, 컴퓨터활용능력 1급, 워드프로세서, OPIc

### 화면 2 — 내 일정 (핵심 화면)

위에서 아래로 이 순서.

**1) D-Day 영역** — 화면 최상단, 가장 눈에 띄는 요소

응시 예정일을 지정한 시험만 카드로 나온다. 가로로 나열하고 임박한 순.

- 카드: 흰 배경, 1px 보더, 라운드 8px, 패딩 16px
- 구성: 종목명(Body) / 이벤트명(Small, 회색) / **D-Day 숫자를 크게(30px Medium, accent 색)** / 날짜(Caption, `2026.10.24`)
- 첫 카드만 accent 보더 1px
- 예시 3장: `정보처리기사 · 실기시험 · D-72 · 2026.10.24` / `한국사능력검정 · 시험 · D-59 · 2026.10.11` / `TOEIC · 시험 · D-39 · 2026.09.21`
- 지정한 시험이 없으면 카드 대신 한 줄 안내: `응시 예정일을 정하면 D-Day를 보여드려요` + 텍스트 링크

**2) 타임라인** — 가로 방향 간트 차트

- 좌측 종목 라벨 컬럼(데스크톱 116px, 모바일 72px) + 우측 트랙
- 가로축은 오늘부터 6개월. 월 경계에 1px 세로 실선, 상단에 `8월` `9월` … 라벨
- 오늘 위치에 accent 색 2px 수직선, 상단에 `오늘` Caption
- 행 높이 40px, 막대 높이 10px, 라운드 3px
- **막대 3종**
  - 원서접수: 흰 배경 + 1px `ink` 보더 (속 빈 막대)
  - 시험: `ink` 꽉 찬 막대
  - 합격발표: 지름 10px 흰 원 + 1px 보더
- 지난 이벤트는 투명도 35%
- 지정한 응시일에는 트랙 위에 **accent 색 작은 마름모 + `예정` Caption**. 그 이벤트의 원래 기간 막대는 투명도 25%로 내림
- 4개 행을 그린다: `정보처리기사`(옆에 `일정 동일 +2` Caption 배지) / `한국사능력검정` / `TOEIC` / `지게차운전기능사`
- `지게차운전기능사`는 연 41회 시행이라 막대를 다 그리면 뭉개진다. 한 행 전체를 옅은 회색 밴드로 칠하고 `6개월 중 20회 시행` Caption + `응시 회차 고르기` 텍스트 버튼

**정보처리기사 행에 넣을 실제 값** — 시험 막대가 대부분 길다는 게 이 화면의 특징이다. 하루짜리 점으로 그리지 말 것.

```
원서접수   07.20 ~ 07.23   (속 빈 막대, 지남)
빈자리접수 08.01 ~ 08.02   (속 빈 막대, 지남)
필기시험   08.07 ~ 09.01   (꽉 찬 막대, 26일)
필기발표   09.09           (빈 원)
실기접수   09.21 ~ 10.19   (속 빈 막대)
실기시험   10.24 ~ 11.13   (꽉 찬 막대, 21일)
최종발표   12.11           (빈 원)
```

**3) 다가오는 일정** — 리스트. `D-39` (Small, tabular) / 종목명 (Body) / 이벤트명 (Small 회색) / 날짜 (Caption). 지난 것 제외

**4) 상시시험** — 확정 일정이 없어 타임라인에 못 올리는 종목. 카드 하나에 `컴퓨터활용능력 1급 · 워드프로세서` / `상시시험 · 접수는 시험일 4일 전까지` / `목표 시기 정하기` 텍스트 버튼

**5) 푸터** — `최종 확인: 2026.08.13` / `일정은 참고용이며 공식 공고가 우선합니다` (Caption, 회색)

헤더에는 `← 시험 바꾸기`와 `링크 복사` 아이콘 버튼.

### 화면 3 — 응시 예정일 지정 (하단 시트 / 데스크톱은 중앙 모달)

타임라인 막대를 누르면 열린다. 폭 420px, 라운드 상단 12px.

- 제목: 종목명 + 이벤트명 (`정보처리기사 필기시험`)
- 부제: `2026.08.07 ~ 2026.09.01 중 하루` (Small 회색)
- 날짜 선택: 해당 기간만 활성인 간단한 월 캘린더. 선택된 날은 accent 원
- **중복 경고** — 고른 날짜에 이미 다른 예정이 있으면 캘린더 바로 아래 한 줄로 표시. 이게 이 화면의 유일한 경고다
  - 좌측에 1.5px 아웃라인 경고 아이콘(warn 색), 텍스트는 `이미 2026.10.24에는 정보처리기사 실기시험이 있습니다`
  - 배경은 warn 색 6% 틴트, 좌측 2px warn 보더, 라운드 0
  - 경고가 떠도 선택은 막지 않는다. 버튼은 그대로 활성
- 하단 버튼: `이 날 볼 예정` (accent 배경) + `취소` (텍스트 버튼)

이 시트의 변형 2개도 함께 만든다.

- **회차 선택형** (`지게차운전기능사`): 캘린더 대신 라디오 목록 5개. 각 항목 `제32회 · 접수 09.14~09.17 · 시험 09.28`
- **상시시험형** (`컴퓨터활용능력 1급`): `상시시험이라 확정 일정이 없어요` / `접수는 시험일 4일 전까지` / 월 칩 `9월` `10월` `11월` / 버튼 `이 시기에 볼 예정`

### 반응형

- 데스크톱 1040px, 모바일 390px 두 가지
- **모바일 타임라인에 가로 스크롤을 쓰지 않는다.** 6개월을 화면 폭에 맞춘다. 안 들어가면 종목 라벨을 축약하고(`정처기`) 월 라벨만 남긴다
- 모바일 D-Day 카드는 가로 스크롤 허용 (카드 폭 148px)
- 모바일 이벤트 상세는 하단 시트

### 만들지 말 것

월간 캘린더 격자. 로그인·회원가입·마이페이지·설정. 알림 벨·푸시 배너. 사이드바 내비게이션. 충돌 심각도 배지나 경고 목록 섹션. 통계 차트·그래프. 히어로 이미지·일러스트. 탭 바.

### 문구

느낌표 없음. 버튼은 동사로 시작. 날짜는 `2026.08.07`, 기간은 `2026.08.07 ~ 2026.09.01`, D-Day는 `D-72`.

## B. 결과가 어긋날 때 넣을 수정 지시문

한 번에 하나만 넣는다. 여러 개를 붙이면 Stitch가 앞의 것을 덮는다.

**시험이 하루짜리 점으로 그려졌을 때**
> 타임라인의 시험 막대를 길게 고쳐줘. 필기시험은 08.07~09.01로 26일, 실기시험은 10.24~11.13으로 21일에 걸친 긴 막대야. 원서접수도 09.21~10.19로 29일짜리 막대야. 점이 아니라 막대다.

**월간 캘린더가 나왔을 때**
> 월간 캘린더 격자를 없애고 가로 간트 차트로 바꿔줘. 세로축은 종목 4개, 가로축은 오늘부터 6개월이고 월 경계에만 세로선이 있어.

**색을 너무 많이 썼을 때**
> 색을 줄여줘. 흑백과 회색이 기본이고, 코발트 블루 #1F4FFF는 선택 상태·D-Day 숫자·주요 버튼에만, 앰버 #B45309는 중복 경고 한 줄에만 쓴다. 그 외 색은 전부 제거.

**충돌 경고 섹션이 생겼을 때**
> 충돌 요약 섹션과 심각도 배지를 전부 삭제해줘. 경고는 응시일 지정 시트 안에서 날짜가 중복될 때 한 줄로만 나온다.

**D-Day가 작게 나왔을 때**
> D-Day 카드를 화면 최상단으로 올리고 숫자를 30px Medium 코발트 블루로 크게 키워줘. 카드에는 종목명, 이벤트명, D-Day 숫자, 날짜 네 줄만 있다.

**모바일에 가로 스크롤이 생겼을 때**
> 모바일 타임라인의 가로 스크롤을 없애고 6개월을 화면 폭에 맞춰줘. 종목 라벨은 `정처기`처럼 줄이고 가로축은 월 라벨만 남긴다. D-Day 카드만 가로 스크롤을 쓴다.

**요소가 많아 답답할 때**
> 여백을 늘리고 요소를 줄여줘. 섹션 간격 32px, 카드 패딩 16px, 보더는 1px #E4E2DC 하나만. 배경색이 들어간 블록과 구분선을 최소화한다.

## C. 받고 나서 확인할 것

| 확인 | 왜 |
|---|---|
| 시험이 긴 막대로 그려졌는지 | 실제 필기 26일·실기 21일. 점으로 그리면 실데이터에서 화면이 무너진다 |
| D-Day가 최상단에서 가장 크게 보이는지 | 이번 개정의 핵심이다 |
| 경고가 시트 안 한 줄로만 있는지 | 별도 충돌 섹션은 만들지 않기로 했다 |
| 액센트가 화면당 3곳 이하인지 | 넘으면 미니멀이 깨진다 |
| 모바일에 가로 스크롤이 없는지 | 6개월을 한눈에 못 보면 이 화면의 존재 이유가 사라진다 |
